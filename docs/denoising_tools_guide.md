# MTPro 去噪工具使用指南

这份指南按“噪声长什么样”选择工具。MT/LMT 时间序列中的自然场变化本身也是信号：不要只凭曲线变平判断去噪成功。建议先复制数据或使用 Pipeline 预览，比较处理前后波形，并检查目标频带内的响应、相位和长周期趋势。

## 快速选择

| 现象 | 先试工具 | 需要留意 |
| --- | --- | --- |
| 少量孤立尖峰/短脉冲 | 自动尖峰筛选；再用中值滤波作比较 | 先只处理红色短脉冲；橙色标记可能是台阶或长异常段，确认后再删 |
| 一段明确的瞬态异常 | 手动异常点/连续区段编辑 | 只框选确认为坏数据的区间；不要把真实地磁脉动当异常删除 |
| 宽带高频粗噪声 | 小波多尺度去噪 | 从保守预设开始，框选局部试验；检查是否损失有效高频成分 |
| 窄带、稳定频率干扰（如工频及谐波） | 零相位频率滤波，通常用陷波 | 按采样率换算频率；滤波范围不要覆盖目标信号频带 |
| 短时正负突变/尖脉冲 | 形态滤波 | 窗口略宽于异常；开闭与闭开对正、负突变的表现不同 |
| 有多尺度振荡/非平稳噪声 | EMD 或 VMD | 先完整重构观察各 IMF/模态，再逐项排除明确噪声；分量序号不等于噪声标签 |
| 缓慢背景变化 | 去除缓慢背景变化（SV） | 仅当慢变部分确属仪器/背景趋势时使用；LMT 有效长周期信息可能也在其中 |
| 连续噪声且信号近似低秩 | Hankel-SVD | 秩越低平滑越强，周期信号也可能被削弱；先用较高秩 |

## 一般操作顺序

1. 先在主图确认异常类型和大致时间范围。无法判断是信号还是噪声时，先保留原数据并缩小处理范围。
2. 选择针对性最强的工具，从默认值或“保守”预设开始。对于有预览的工具，先预览，再调整参数。
3. 一次只改变一个参数，记录处理范围和参数。不要连续叠加多个强滤波器来追求平滑。
4. 对照原始序列检查异常附近、异常两侧边界、长周期趋势、缺失值和波形幅值。
5. 预览可信后再应用；最终确认前保留可回退的原始数据或 Pipeline 副本。

## NaN 与缺失数据

去噪和分解算法会先裁掉计算范围两端的 NaN/无穷值，只对不超过 10 个连续采样点的内部缺口做线性插值，再执行运算，最后把原来非有限的位置恢复为 NaN。超过上限的缺口会保留为边界，算法在缺口两侧分段处理；不会跨长缺口连线。

插值只用于算法内部，不表示缺失观测已被真实恢复。短缺口周围结果仍建议检查；整段缺测或只有极少有效点时，算法会跳过相应段。自动尖峰筛选也会基于短缺口插值序列估算局部背景，但不会把原 NaN 当作新的尖峰候选。当前上限统一为 10 点，定义见 `core/algorithms/missing.py`。

## 各工具怎么用

### 自动尖峰筛选

用于孤立、短时、幅度突出的脉冲。窗口点数决定局部中位数/MAD 的估计范围；窗口应比脉冲宽，同时不应大到跨过明显的背景变化。鲁棒阈值 σ 越小，检出的候选越多；最大脉冲宽度限定自动删除的短事件长度。

先点击“重新筛选并预览”。红点是默认将置为 NaN 的短脉冲；橙点代表长异常段、潜在台阶或边界候选，默认只标记。只有确认橙点确属坏数据后才勾选“同时删除橙色标记点”。处理结果中的 NaN 是有意保留的坏点标记，后续分析前应按项目流程处理缺测。

### 小波多尺度去噪

先在主图框选一段包含异常及其周围背景的区域。选择预设并查看频带 EQ：横轴从低频到高频，纵轴为各分解层增益，1 表示保持，0 表示移除该层。拖节点后会转为手动模式；松手后可自动预览。能量对比标签用于查看分层能量变化。

LMT 优先从“保守去噪（优先保长周期）”开始，并重点对比长周期趋势、台阶两侧和事件形态。高频粗噪声预设可能同时衰减有效高频成分。小波预设只提供参数起点，不等价于论文中自动噪声识别、Hampel 检测或台阶补偿。

### 滑动中值滤波

适合孤立尖峰和短脉冲。窗口点数使用奇数；建议从 3 或 5 点开始，逐步增加。窗口过大时会压平窄峰和快速变化。缺失值会被保留；过短的连续有效段可能跳过处理。

### 零相位频率滤波

按已知频带选择低通、高通、带通、带阻或陷波。界面中的截止值是奈奎斯特频率的比例：实际频率为“比例 × 采样率 / 2”。窄带固定干扰优先尝试陷波；宽频噪声才考虑低通/带通。提高阶数会让过渡带更陡，也更容易在边界或数据缺口附近出现伪影。检查目标信号的频谱和时域波形后再应用。

### 形态滤波

开/闭运算对局部正、负突变的响应不同。窗口点数决定形态结构元素的时间尺度；从略宽于待抑制突变的窗口开始。先比较 opening、closing、open-close 和 close-open 的预览，确认有效脉冲、台阶和波峰没有被误削。

### EMD 经验模态分解

先将“保留 IMF”设为 `all` 并运行重构作为基准。IMF 按提取顺序从高频到低频编号；逐步移除最前面的高频 IMF，比较每次重构。对 LMT，通常要保留低频残差。若分量里同时含有有效信号和干扰，不要仅凭分量序号删除。

“最大 IMF 数”限制分解数量；筛分次数和相对变化阈值控制单个 IMF 的迭代。含 NaN 的数据按连续有效段分别分解。短段可能因达不到最短点数而跳过。

### VMD 模态分解

先用默认 `保留模态 = all` 运行，观察各模态的中心频率和能量；再只排除频率特征明确对应干扰的模态。模态按中心频率由低到高编号，`K` 是分解模态数，α 控制带宽约束。调整 K 或 α 后重新观察中心频率；不要假设某个固定编号总是噪声。LMT 中最低频模态通常需要特别谨慎。

### 去除缓慢背景变化（SV）

点击“预览平滑背景”，上图查看估计背景，下图查看背景相减结果。平滑窗口和锚点间隔均以采样点计；窗口越大，背景越平滑，间隔越大，背景锚点越稀。只在缓慢分量被确认是应去除的背景漂移时应用。LMT 的慢变化可能包含有效长周期场，不能仅凭“趋势明显”就减去。

### Hankel-SVD

嵌入窗口点数决定轨迹矩阵的时间尺度，保留秩决定重构复杂度。先用较高秩观察温和效果，再逐步降低秩；对不同窗口、不同秩做结果对比。SVD 会优先保留能量较大的结构，真实周期信号也可能被截断，不能只看噪声变小。

## 常见判断

- 若处理后异常边界出现新的跳变，缩小处理范围或降低强度，并检查边缘扩展/滤波窗口。
- 若长周期波形振幅或相位关系明显变化，撤销处理，减少低频层增益衰减、提高保留秩，或改用局部处理。
- 若工频干扰仅在少数频点突出，先试陷波，不要用全频段强降噪。
- 若异常是方波、阶跃或持续漂移，尖峰滤波通常不适用；需要专门的阶跃/背景处理，并核实它不是有效变化。
- 自动工具只提供候选和起始参数，最终以波形及后续 MT 响应质量共同判断。
