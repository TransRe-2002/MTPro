# Bundled EMTF Reference

This directory contains reference material migrated from
`/home/transen5/Project/emtf-pywrap` so the EMTF wrapper, binaries, docs, and
examples can be managed from this repository.

- `doc/`: upstream EMTF manuals in PDF, PostScript, and TeX form.
- `examples/`: upstream EMTF sample configs, data, Fourier coefficients, and
  output files.
- `config/`: compact config templates used by the Python wrapper.
- `pywrap_examples/`: small Python wrapper examples from `emtf-pywrap`.
- `EMTF_README`: upstream EMTF README.

Runtime code lives separately under `python/src/emtf`, and bundled executables
live under `python/src/bin`.
