# 小波去噪策略预设

小波去噪预设不是一组固定的“层数 + 阈值点数”，而是一套可保存、可复现的处理策略。处理前应使用预览，并对照去噪前后的能量谱、视电阻率和相位；任何预设都不应替代数据质量检查。

## 内置预设

| 预设 | 适用情况 | 核心策略 |
| --- | --- | --- |
| 自适应保守（推荐） | 一般 MT 时序 | DWT、sym6、软阈值、逐层 SureShrink；按 3600 s 保护周期选层，近似项不阈值化。 |
| 常规宽带降噪 | 高频随机噪声较明显 | DWT、sym4、软阈值、逐层 SureShrink；按 300 s 保护周期选层。 |
| 边界安全去噪 | 截取边缘或短时突变附近 | SWT、sym6、软阈值、逐层 SureShrink；计算量高于 DWT，但不下采样，较不受采样点平移影响。 |
| 脉冲/尖峰/平滑降噪（旧版固定） | 复现旧工程 | 保留旧的通用阈值、固定层数和点数 padding；名称明确标为旧版，不能作为新的默认处理策略。 |

尖峰应优先通过“尖峰处理”工具识别、确认和删除。小波阈值是尺度选择性降噪，不应被当作无条件的自动异常点删除器。

## 参数含义

- **SureShrink（逐层自适应）**：每个细节层用上下文系数的 MAD 估计噪声尺度，再按 SURE 选择软阈值，并限制不超过通用阈值。预览日志会列出每层实际阈值。
- **通用阈值（兼容）**：`MAD × sqrt(2 log N) × 阈值倍数`；用于复现旧参数，不建议作为默认策略。
- **按保护周期**：根据采样率和保护周期自动确定分解层数。第 `J` 层近似项的频率上界约为 `fs / 2^(J+1)`，因此保护周期换了采样率后仍保持物理意义。
- **边界扩展（秒）**：先以秒换算为采样点再截取局部窗口；比固定点数更适合不同采样率的数据。
- **SWT（平移稳定）**：对局部窗口进行对称补齐后做非下采样变换和重构，适合需要降低平移伪影的场景；不支持 Wavelet Packet 的自动保护周期策略。

导出的 TOML 预设版本为 2，包含 `threshold_method`、`level_policy`、`protect_period_seconds`、`padding_unit` 与 `padding_seconds`。旧版 TOML 仍可导入，并按固定点数/通用阈值解释。

## 依据

SureShrink 的逐层自适应阈值来自 Donoho 与 Johnstone 的 SURE 风险最小化思路；SWT 的选择对应 Coifman 与 Donoho 提出的平移不变去噪。MT 数据可同时含有跨尺度的自然信号与噪声，因此预设只提供保守起点，结果必须结合阻抗输出验证。
