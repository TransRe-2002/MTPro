## 1 国内外研究现状

### 1.1 大地电磁时间序列质量控制与稳健处理

大地电磁法以天然电磁场为场源，观测信号弱且具有宽频带特征，原始时间序列中的非平稳干扰、离群观测和局部缺测会经频谱估计与传递函数求解传递到阻抗结果中。张昆等[1]将 MT 数据处理概括为时频转换、去噪、阻抗张量和倾子矢量估计等环节；葛双超和李斌[2]进一步归纳了场源、地质和人文干扰的特点及相应信噪分离方法。由此可见，时间序列质量控制是后续阻抗估计与资料解释的前提，而不是与主体处理相分离的辅助步骤。

国际上，稳健统计是 MT 数据处理的重要技术路线。Chave 等[3]讨论了在局部非平稳和孤立离群值条件下，对功率谱、相干与传递函数进行稳健估计的思路，为异常观测的自动识别和自适应加权提供了统计基础。Egbert[4]面向多台站 MT 数据提出稳健处理框架，说明远参考、阵列观测与多变量统计可用于改善信噪比、诊断相干噪声及降低估计偏差。Smirnov[5]则采用高崩溃点的重复中位数估计与频谱分段处理，以提高含大误差数据时处理结果的稳定性。这些工作共同表明：稳健估计能够降低异常值影响，但其效果仍依赖于异常比例、噪声相干性、观测阵列和数据分段方式，不能替代针对具体异常形态的前置质量控制。

国内关于强干扰数据处理的研究也在由单一滤波向“筛选—稳健估计—响应约束”的组合策略发展。王培杰等[6]针对实测强干扰数据，结合回归 M 稳健估计、多参数筛选和 Rhoplus 约束开展处理；该工作说明，仅靠单一去噪算子难以覆盖复杂观测环境，需要将数据筛选与后续响应质量评价结合起来。对于本课题而言，稳健估计和远参考属于重要的下游阻抗处理能力；短脉冲飞点自动筛选则定位于时间序列进入这些步骤之前的保守质量控制，不宜混同为对稳健估计方法的替代。

### 1.2 面向人文噪声和非平稳干扰的去噪方法

针对 MT 信号的非平稳性、宽频带性及人文干扰的多样性，时频分析和多尺度分解是国内研究中的常见路线。罗皓中等[7]将经验模态分解与小波阈值去噪结合，用于长周期 MT 时间序列的时域去噪；万云霞等[8]利用小波变换的多尺度分析能力，并针对不同人文干扰调整母小波、分解层数和阈值等参数。此类方法能够在特定频带或尺度上衰减噪声，但算法参数、信号保真度以及不同干扰环境下的适用性需要结合实测数据加以评价。

除小波与模态分解外，数学形态学和频域特征方法也被用于 MT 噪声压制。汤井田等[9]针对非线性、非平稳和非最小相位的 MT 信号，研究了数学形态滤波的噪声压制应用；郭荣文等[10]利用频率域信号形态与聚类算法分离信号和强干扰噪声，并以视电阻率和相位曲线检验处理效果。近年来，周瑞[11]围绕长时段干扰噪声压制开展系统研究，反映出长记录中持续性干扰与瞬态异常需要采用不同处理策略。

国际研究同样关注脉冲类干扰的识别及其对响应结果的影响。徐天和罗鸣[12]将频域 Hampel 识别用于海洋 MT 脉冲噪声抑制，并在合成与实测数据上讨论处理前后视电阻率和相位响应的变化。这类工作提示，脉冲噪声处理的评价不应只停留在时域波形“更平滑”，还应考察其是否改善或至少不劣化后续阻抗响应。

上述方法的共同目标是增强有效信号、减弱干扰成分，但它们通常针对具有特定时频结构、持续时长或统计特征的噪声。对于单点或少量连续采样点构成的极端脉冲飞点，若直接使用全局去噪或较强的重构方法，可能改变正常瞬态细节，也可能把真实台阶、长干扰段与飞点混为一类。因此，采用局部鲁棒基线判别短脉冲、保留长异常段和潜在台阶供人工复核，是对现有方法的补充性质量控制策略，而不是试图以一种规则覆盖所有噪声类型。

### 1.3 自动筛选、异常检测与学习型方法

在数据规模增大和人工筛选成本上升的背景下，自动质量控制逐渐成为 MT 数据处理的重要方向。Platz 和 Weckmann[13]基于马氏距离、稳健协方差估计与磁场方向约束，提出受噪数据的自动预筛选方法。该研究指出，统计距离可以识别散点异常和附加数据簇，但当受噪数据占多数时，自动判据会受到限制；此时应结合物理约束、人工输入或其他补充规则。该结论对自动化模块的设计具有直接启示：自动筛选应输出可解释的候选与诊断信息，并为用户保留复核和撤销空间。

国内近期工作开始引入聚类和机器学习方法。郭荣文等[10]从频率域形态特征出发实施自动聚类；张培林和雷万里[14]将弱监督学习用于 MT 噪声检测和分类，利用异常检测模型进行候选识别，再通过 CNN-BiLSTM 完成噪声类型分类。学习型方法在复杂模式提取上具有潜力，但模型训练依赖数据集代表性、标注质量和跨测区泛化能力，且异常类别与具体处理动作之间仍需建立可靠映射。因此，在当前以桌面程序和工程数据处理为目标的研究中，可先采用参数明确、结果可解释、可人工确认的鲁棒规则完成短脉冲飞点质量控制；后续再将学习型检测作为候选生成或辅助判别模块接入插件框架。

### 1.4 MT 数据处理软件、数据组织与可复现工作流

除算法研究外，数据格式、元数据和软件工作流直接影响处理结果能否复查和复用。Kirkby 等[15]介绍了 MTPy 软件包在 MT 数据处理、分析、建模和可视化方面的开源实践，强调代码标准化、测试和文档对社区使用的重要性。Kappler 等[16]给出的 Aurora 工作流以 MTH5 和 `mt_metadata` 为基础，通过数据表和 JSON 参数组织单站与远参考传递函数估计，体现了“数据—元数据—处理参数—输出结果”可管理化的思路。国内方面，杨凯[17]实现了 MTU 系列时间序列的 Python 读写和时频分析界面；陈小斌等[18]较早讨论了 MT 资料处理与解释的 Windows 可视化集成系统。这些研究和软件为 MT 数据读写、功能集成与工作流设计提供了参考。

然而，软件能力不能仅以“是否包含某个算法”衡量。面向 LMT 时间序列处理，至少还需处理以下关系：原始数据与处理副本的边界、交互式人工修改与参数化自动处理的边界、处理顺序与参数记录、处理结果写回与导出，以及大数据量下的显示和计算效率。若这些关系未被统一建模，即使单个算法有效，也难以形成可审计、可复现的处理流程。因此，将插件接口、处理流水线、处理配方、批处理和人工确认机制整合到同一数据模型中，是程序实现类论文可形成研究闭环的重要条件。

### 1.5 现有研究评述与本文切入点

综上，国内外针对 MT 数据噪声已形成稳健估计、远参考与多台站处理、时频去噪、形态学滤波、自动筛选、聚类和学习型检测等多条技术路线。现有工作并非不足，而是各自面向不同噪声形态、数据域和处理阶段：稳健估计主要降低频谱或传递函数估计中异常观测的影响；远参考和多台站方法利用空间观测关系抑制噪声；小波、EMD 和 VMD 等方法强调时频或尺度分离；自动筛选和学习方法则侧重候选异常识别与分类。实际 LMT 数据处理需要根据异常的持续宽度、局部统计特征、跨通道一致性和对后续阻抗的影响选择或组合这些方法。

本文不将“自动跳点筛选”表述为对所有 MT 噪声的普适去噪算法，而将其限定为面向短脉冲飞点的保守质量控制模块：在可设置点数的重叠窗口内，以中位数和 MAD 构建局部鲁棒基线；仅将超过阈值且连续宽度不超过设定值的候选样点改为 `NaN`；对长异常段、潜在台阶和记录边界候选仅作诊断标记，并保留原有手动框选删除功能。其研究价值需通过合成数据的检出率/误删率、实测数据的时域与阻抗响应对比，以及处理参数和结果的可重放性共同证明。

在系统层面，本文以 MTPro 为载体，研究统一时间序列数据模型、跨平台可视化、插件化处理与可复现流水线的协同设计。Python/Rust 协同仅服务于大样本数据的渐进显示和计算热点；若要作为论文贡献，应提供相同硬件、相同输入、相同功能条件下的耗时和内存对比。由此，论文的主线可概括为：**以可复现处理工作流承载可解释的短脉冲质量控制方法，并以数据质量与运行性能实验验证其有效性。**

## 2 可直接放入论文的简短结论段

国内外研究表明，大地电磁噪声处理已从传统滤波逐步发展为稳健统计、阵列协同、时频分解、自动筛选和智能识别等多方法并行的技术体系。不同方法在处理对象、适用数据域和参数依赖性方面存在差异，难以由单一算法完全覆盖。面向长周期大地电磁时间序列，除提高局部异常的识别与处置能力外，还需要保证人工操作、自动处理参数和结果导出过程可记录、可复核和可重放。基于此，本文将短脉冲飞点筛选、人工确认和参数化流水线整合到跨平台可视化处理程序中，并通过合成与实测数据实验评价其对数据质量、阻抗响应稳定性和处理效率的影响。

## 4 写作边界

- 不要写“国内外没有 MT 可视化软件”或“现有方法均无法自动处理噪声”；[15]-[18] 已表明软件和自动化研究长期存在。
- 不要写“本文方法可消除所有噪声”或“自动筛选不需要人工复核”；[13] 明确讨论了统计自动筛选在高污染比例下的局限。
- 未完成实测阻抗对比前，只能写“本文将评价/验证对阻抗响应的影响”，不能写“本文方法显著提高阻抗精度”。
- Rust 的表述应限定为性能工程与跨语言协同；除非有方法学设计和对照实验，不单独作为地球物理算法创新。
