## 引言

大地电磁测深（magnetotelluric sounding，MT）以天然电磁场为场源，通过观测地表相互正交的电场和磁场分量，估计地下介质的电性结构。该方法具有探测深度大、频带宽、设备相对轻便且不受高阻层明显屏蔽等特点，已广泛服务于深部资源与能源勘查、地壳—岩石圈结构研究、地热调查和灾害地球物理等任务[1]。长周期大地电磁（long-period magnetotellurics，LMT）面向更低频段的天然场响应，其有效信号弱、观测记录长，对连续时间序列的完整性、台站元数据和数据处理质量提出了更高要求。

天然场信号不可控以及观测环境日益复杂，使原始 MT 时间序列不可避免地受到多类噪声污染。输电线路、交通设施、通信设备和工业装置等人文源可引入稳定或间歇性电磁干扰；仪器瞬态故障、采集链路异常和自然扰动还会形成局部非平稳片段或孤立异常点[2-3]。这些异常若直接进入频谱估计和传递函数求解，可能使阻抗张量、视电阻率和相位发生偏移或畸变，进而降低地质解释的可信度[1-2,7]。因此，时间序列质量控制并非后处理中的附属环节，而是连接原始观测、阻抗估计与解释反演的基础环节。

围绕含噪 MT 数据处理，国内外已形成较为丰富的方法体系。稳健谱估计和稳健传递函数估计通过降低离群观测在回归与叠加中的影响，提高了非高斯噪声条件下结果的稳定性[3,5]；远参考与多台站稳健处理进一步利用参考台或阵列观测，识别并缓解非相干或部分相干干扰[4]。在自动质量筛选方面，Platz 和 Weckmann 使用马氏距离、稳健协方差估计及磁场约束，对受噪时间段进行预筛选，说明纯统计判据需要结合物理约束和人工判断使用[6]。针对脉冲类异常，徐天和罗鸣利用频域 Hampel 识别器压制海洋 MT 数据中的脉冲噪声，并通过合成与实测数据讨论了其对视电阻率和相位结果的改善[7]。近年来，面向强干扰实测数据的多参数筛选、稳健估计与响应约束组合方法也在持续发展[8]。这些研究为不同类型噪声的识别、筛选与抑制提供了重要基础，但其适用条件、输入数据格式和操作流程各不相同。

从实际生产与科研流程看，数据处理仍面临两方面问题。其一，时间序列导入、可视化浏览、异常判别、处理参数管理、阻抗输出和结果复核往往分散在多个工具中；人工框选等操作虽具有必要的灵活性，却难以完整记录和重放。其二，LMT 数据量较大，若缺少高效的数据组织、渐进显示和计算机制，交互式质量检查的效率会明显下降。已有 MTPy、Aurora 等开源工具在 MT 数据处理、元数据管理和可配置工作流方面提供了有益实践[9,11]；国内也已有针对 MTU 时间序列读写和可视化集成处理的探索[10,12]。这表明，以统一数据模型连接时间序列、元数据、处理参数和结果，并将自动化算法与人工复核共同纳入可追溯工作流，具有明确的工程需求和研究价值。

基于上述认识，本文面向长周期大地电磁时间序列处理需求，设计并实现跨平台可视化处理程序 MTPro。系统以带时间索引的多通道电磁数据为核心对象，围绕数据导入导出、交互式浏览、插件化处理、处理流水线、阻抗结果输出等环节建立统一流程。对于“单点或少量连续采样点构成、且相对局部基线出现极端偏离”的短脉冲飞点，本文将其与持续台阶和长异常段区分处理：在重叠点窗口内利用中位数和 MAD（median absolute deviation）构建鲁棒局部基线，仅将同时满足阈值和最大持续宽度条件的候选点置为缺失值（`NaN`）；对于潜在台阶、长异常段和边界候选只作标记，由人工或其他专用处理工具继续判别。该设计保留原始时间轴和手动删除能力，避免将自动筛选扩展为对所有异常类型的无差别修改。

本文的重点不在于以新的统计量替代已有稳健方法，而在于将适用于短脉冲飞点的保守筛选规则、人工复核和参数化重放整合进同一处理环境：Classic 模式下先展示候选位置与诊断信息，再由用户确认写入；Pipeline、配方和批处理模式下则保存窗口点数、重叠比例、阈值和最大脉冲宽度等参数，以相同规则重复执行。为改善大数据量条件下的显示和计算体验，系统还在适合的热点环节采用 Python 与 Rust 协同实现；这一部分属于软件性能支撑，应通过基准测试证明其效果，而不宜脱离处理任务单独表述为算法创新。

本文拟开展的主要工作如下：

1. 建立面向 MT 时间序列的统一数据组织与交换机制，支持多通道数据、时间索引、元数据及常用数据格式之间的可靠转换；
2. 设计插件化、参数化的数据处理架构，使处理工具能够以可记录、可重放的方式接入可视化程序，并保留人工交互处理的灵活性；
3. 实现面向短脉冲飞点的自动筛选插件，研究窗口点数、窗口重叠、鲁棒阈值和最大脉冲宽度对筛选结果的影响，并与手动处理结果进行对照；
4. 通过合成异常数据和实测 LMT 数据，从异常识别结果、处理前后阻抗响应稳定性、流程可复现性以及运行时间和内存开销等方面评价系统与方法的有效性。

全文可按以下结构组织：第一章介绍研究背景、国内外研究现状和本文工作；第二章说明 MT 时间序列处理基础、数据模型与总体架构；第三章描述 MTPro 的数据管理、可视化、插件和处理流水线设计；第四章给出短脉冲飞点自动筛选方法及其实现；第五章利用合成与实测数据开展对比实验和性能测试；第六章总结全文，并讨论尚未覆盖的复杂干扰、跨通道判据及后续扩展方向。
